# Week 14 ColPack Baselines and Ordering Targets Plan

## Goal

The goal of Week 14 is to generate distance-1 ColPack baseline results and ordering targets for the expanded Week 13 dataset.

The expanded dataset now contains 15 graph instances:

- 5 original graphs from the initial prototype dataset,
- 10 newly accepted sparse matrix graphs from the Week 13 expansion.

The purpose of this week is to connect the expanded raw graph dataset to the learning pipeline by generating verified heuristic coloring results and node-level ordering targets.

## Main Pipeline

The Week 14 pipeline is:

```text
expanded matrix dataset
→ graph construction
→ ColPack distance-1 coloring
→ saved ColPack output files
→ parsed benchmark table
→ extracted vertex orderings
→ normalized node-level ordering targets
```

Week 14 will use three ColPack ordering strategies:

- SMALLEST_LAST
- LARGEST_FIRST
- NATURAL

SMALLEST_LAST remains the primary ordering target for supervised GNN training. LARGEST_FIRST and NATURAL are included as additional heuristic baselines for comparison.

## Ordering Target Extraction

The `SMALLEST_LAST` ColPack outputs were used to build node-level ordering targets for the expanded dataset.

The target file is:

```text
data/processed/initial_graph_coloring_dataset/ordering_targets/smallest_last_ordering_targets_week14_expanded.csv
```

The target construction follows the same design as the initial learning prototype:

- vertices appearing earlier in the SMALLEST_LAST ordering receive higher target scores,
- vertices appearing later receive lower target scores,
- target scores are normalized to the range [0, 1],
- one target row is stored per graph vertex.

The expanded target file contains 3563 node-level rows, matching the total number of vertices across the 15 graph instances.

This confirms that the expanded ColPack ordering outputs can be used as supervision for the next GNN training stage.
